= Algebra Sofii - Algebraic Equation Generator
:toc:
:toclevels: 3

A sophisticated algebraic equation generator designed for 12-year-old students, creating complex yet solvable linear equations through systematic complication algorithms.

== Overview

Algebra Sofii generates algebraic equations by starting with simple base equations and systematically applying mathematical complications that preserve the solution while increasing complexity. The system uses a complexity budget system to ensure generated equations remain appropriate for the target audience.

== Architecture

The system is organized into several key modules:

=== Expression System

The expression system uses a tree structure to represent algebraic expressions:

* **Base Types**: `Integer`, `Unknown` (representing variables like 'x')
* **Operations**: `Addition`, `Multiplication`, `Equals`
* **Modifiers**: `ChangedSign` (negation), `Inverted` (reciprocal)
* **Indexing**: `ExpressionIndex` for navigating expression trees

Each expression has a `complexity()` method that returns a numerical complexity score used for budget management.

== Complication System

=== Algorithm Overview

The core algorithm works as follows:

1. **Start** with a simple base equation (e.g., `x = 5`)
2. **Select** complications randomly based on weighted probabilities
3. **Apply** complications that preserve mathematical equivalence
4. **Track** complexity to stay within budget limits
5. **Repeat** until target complexity is reached

=== Complication Types

==== Expression Complications

These complications modify subexpressions within equations:

**AddZeroComplication**::
Replaces `expr` with `zero_expr + (expr - zero_expr)`, mathematically equivalent to adding zero.
+
_Minimal complexity_: `zero_expr.complexity() + 2.0`
+
_Example_: `x` → `3 + (x + (-3))`

**MultiplyByOneComplication**::
Replaces `expr` with `one_expr * (expr / one_expr)`, mathematically equivalent to multiplying by one.
+
_Minimal complexity_: `one_expr.complexity() + 2.0`
+
_Example_: `x` → `2 * (x / 2)`

**InsertBracketsComplication**::
Groups two operands in additions with 3+ terms, optionally with negation.
+
_Minimal complexity_: `1.0` (or `2.0` with negation)
+
_Example_: `a + b + c` → `(a + b) + c` or `-(a + b) + c`

**NegateComplication**::
Wraps an expression with a sign change.
+
_Minimal complexity_: `1.0`
+
_Example_: `x + 2` → `-(x + 2)`

**InvertComplication**::
Wraps an expression with reciprocal operation.
+
_Minimal complexity_: `1.0`
+
_Example_: `x + 2` → `1/(x + 2)`

==== Equation Complications

These complications operate on both sides of equations:

**AddToEquationComplication**::
Adds the same expression to both sides of an equation.
+
_Minimal complexity_: `2 * expr.complexity()`
+
_Example_: `x = 5` → `x + 3 = 5 + 3`

**MultiplyEquationComplication**::
Multiplies both sides of an equation by the same expression.
+
_Minimal complexity_: `2 * expr.complexity()`
+
_Example_: `x = 5` → `2x = 10`

=== Complexity Budget System

Each complication has:

* **Minimal Complexity**: The minimum complexity it will add
* **Maximal Complexity**: The maximum complexity it can add
* **Budget Checking**: Ensures complications fit within remaining budget

The system uses a two-step validation:
1. **Theoretical Check**: Verify minimal complexity fits budget
2. **Actual Check**: Validate generated complication complexity

=== Weighted Selection Algorithm

Complications are selected using weighted random choice:

[source,python]
----
EXPRESSION_COMPLICATION_WEIGHTS = {
    'AddZeroComplication': 2.0,
    'MultiplyByOneComplication': 2.0,
    'InsertBracketsComplication': 3.0,  # Higher weight - often applicable
    'NegateComplication': 1.0,
    'InvertComplication': 0.5,  # Lower weight - can cause division issues
}

EQUATION_COMPLICATION_WEIGHTS = {
    # All expression complications plus:
    'AddToEquationComplication': 2.5,
    'MultiplyEquationComplication': 1.5,
}
----

== Main Algorithm: EquationWithSolution

=== Core Methods

**`add_random_complication(max_complexity, random_stream)`**::
1. Calculate remaining complexity budget
2. Filter applicable complications by minimal complexity
3. Select complication using weighted random choice
4. Generate complication instance with budget constraints
5. Apply complication and update cached form

**`randomize(random_stream, max_complexity)`**::
Repeatedly calls `add_random_complication()` until target complexity is reached or no more complications can be applied.

== Usage Examples

=== Basic Usage

[source,python]
----
from algebra_sofii import EquationWithSolution
import random

# Create equation: x = 5
eq = EquationWithSolution(solution=5)

# Add complications up to complexity 15
random_stream = random.Random(42)  # For reproducibility
eq.randomize(random_stream, max_complexity=15.0)

# Get the complicated equation
current_equation = eq.get_current_equation()
print(current_equation)  # e.g., "2 * (3 + (x + (-3))) / 2 + 1 = 6"

# Verify solution is preserved
assert eq.verify_solution()  # Should be True
----

=== Custom Complication Application

[source,python]
----
from algebra_sofii.complications import AddZeroComplication
from algebra_sofii.expressions import ExpressionIndex, Integer

# Apply specific complication
index = ExpressionIndex([0])  # Target left side
zero_expr = Integer(7)
complication = AddZeroComplication(index, zero_expr)

eq = EquationWithSolution(solution=10)
eq.apply_complication(complication)
# Result: 7 + (x + (-7)) = 10
----

== Design Principles

=== Mathematical Equivalence
All complications preserve the mathematical truth of equations. The original solution remains valid after any sequence of complications.

=== Complexity Management
The complexity budget system ensures generated equations remain appropriate for the target difficulty level while allowing fine-grained control.

=== Extensibility
The complication system is designed for easy extension. New complication types can be added by:

1. Implementing the `Complication` interface
2. Adding to weight configurations
3. Including in class mappings

=== Deterministic Generation
Given the same random seed, the system produces identical results, enabling reproducible test generation.
