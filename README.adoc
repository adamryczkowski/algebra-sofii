= Algebra Sofii
:toc:
:toclevels: 3

A Python library for generating algebraic equations suitable for 12-year-old students to practice solving.

== Overview

Algebra Sofii creates random algebraic equations with a single unknown variable that always solve to positive integers between 1 and 9. The library uses a sophisticated expression tree system and complication algorithms to generate equations of varying difficulty while maintaining mathematical correctness.

== Features

* **Expression Tree System**: Hierarchical representation of mathematical expressions
* **Random Generation**: Creates equations with configurable complexity
* **Solution Preservation**: All generated equations solve to predetermined integer solutions (1-9)
* **Complication System**: Applies mathematical transformations that preserve solutions while increasing difficulty
* **SymPy Integration**: Full compatibility with SymPy for symbolic mathematics
* **Comprehensive Testing**: Extensive test suite with pytest features

== Command-Line Interface

After installation, Algebra Sofii provides a command-line tool for quickly generating algebra equations suitable for student practice.

=== Basic Usage

[source,bash]
----
# Generate an equation with default settings
algebra-equation

# Example output:
# Generated Algebra Equation:
# ========================================
# Equation: 3·x + 7 = 22
# Solution: x = 5
# Complexity: 5.0
# ✓ Solution verified
----

=== Command Options

The `algebra-equation` command supports the following options:

==== Cost Target (`-c`, `--cost-target`)

Controls the complexity of the generated equation (default: 5.0):

[source,bash]
----
# Simple equations (complexity 1-2)
algebra-equation -c 2.0
# Output: x = 7

# Medium complexity (complexity 3-4)
algebra-equation -c 4.0
# Output: 2·x = 14

# Higher complexity (complexity 5-7)
algebra-equation -c 6.0
# Output: 2·x + 5 = 17

# Complex equations (complexity 8+)
algebra-equation -c 10.0
# Output: (3·x + 4) + 2 = 2·x + 11
----

==== Random Seed (`--seed`)

For reproducible results, specify a seed value:

[source,bash]
----
# Generate the same equation every time
algebra-equation --seed 42

# Use different seeds for variety
algebra-equation --seed 123
algebra-equation --seed 456
----

==== Help

[source,bash]
----
algebra-equation --help
----

=== Complexity Levels

The cost-target parameter controls equation difficulty:

* **1-2**: Simple constants or basic linear terms
  - Examples: `x = 5`, `3·x = 12`

* **3-4**: Linear expressions with coefficients
  - Examples: `2·x = 8`, `x + 3 = 7`

* **5-7**: Full linear expressions with complications
  - Examples: `2·x + 3 = 11`, `3·x - 4 = 8`

* **8+**: Complex equations with multiple complications
  - Examples: `(2·x + 1) + 3 = x + 9`, `2·(x + 3) = 3·x + 1`

== Quick Start

=== Basic Usage

[source,python]
----
from algebra_sofii import EquationWithSolution
import random

# Create a random stream for reproducible results
random_stream = random.Random(42)

# Generate an equation that solves to x = 5
eq_generator = EquationWithSolution(solution=5)

# Add complications to make it more interesting
for _ in range(3):
    complication = eq_generator.random_complication(max_complexity=15.0, random_stream=random_stream)
    eq_generator.apply_complication(complication)

# Get the final equation
equation = eq_generator.get_current_equation()
print(f"Solve: {equation}")
print(f"Solution: x = {eq_generator.solution}")

# Verify the solution is correct
print(f"Verification: {eq_generator.verify_solution()}")
----

=== Working with Expressions

[source,python]
----
from algebra_sofii import *

# Create basic expressions
x = Unknown()
five = Integer(5)
two = Integer(2)

# Build complex expressions
linear_expr = Addition([Multiplication([two, x]), five])  # 2*x + 5
equation = Equals(linear_expr, Integer(15))  # 2*x + 5 = 15

# Evaluate expressions
result = linear_expr.evaluate(3)  # Evaluates 2*3 + 5 = 11
print(f"2*x + 5 where x=3: {result}")

# Convert to SymPy
sympy_expr = equation.to_sympy_expr()
print(f"SymPy equation: {sympy_expr}")
----

== Core Concepts

=== Expression Hierarchy

The library uses a tree-based representation of mathematical expressions:

* **`Expression`**: Base class for all mathematical expressions
* **`Integer`**: Represents integer constants
* **`Unknown`**: Represents variables (typically 'x')
* **`Addition`**: Represents sum of multiple expressions
* **`Multiplication`**: Represents product of multiple expressions
* **`ChangedSign`**: Represents negation of an expression
* **`Inverted`**: Represents reciprocal (1/x) of an expression
* **`Equals`**: Represents equations with left and right sides

=== Expression Operations

All expressions support these operations:

[source,python]
----
expr = Integer(5)

# Basic transformations
negated = expr.negated()        # -5
inverted = expr.inverted()      # 1/5
added = expr.add_expression(Integer(3))     # 5 + 3
multiplied = expr.multiply_by(Integer(2))   # 5 * 2

# Complex transformations that preserve value
add_zero = expr.add_zero(Integer(7))        # 7 + (5 - 7) = 5
mult_one = expr.multiply_by_one(Integer(3)) # 3 * (5 / 3) = 5
----

=== Complication System

The complication system applies mathematical transformations that preserve equation solutions while increasing complexity:

* **`ExpressionComplication`**: Modifies subexpressions using add-zero or multiply-by-one
* **`EquationComplication`**: Applies operations to both sides of equations
* **`EquationElementMove`**: Moves terms between equation sides

=== Random Generation

[source,python]
----
from algebra_sofii import random_expression, random_nonzero_expression

# Generate expressions with target complexity
simple_expr = random_expression(random_stream, complexity_target=2.0)
complex_expr = random_expression(random_stream, complexity_target=5.0)

# Generate expressions that don't evaluate to zero

== Advanced Usage

=== Custom Expression Building

[source,python]
----
# Build: (2*x + 3) = (x + 8)
left_side = Addition([
    Multiplication([Integer(2), Unknown('x')]),
    Integer(3)
])
right_side = Addition([Unknown('x'), Integer(8)])
equation = Equals(left_side, right_side)

print(f"Equation: {equation}")
print(f"Solution check (x=5): {equation.left.evaluate(5)} = {equation.right.evaluate(5)}")
----

=== Controlled Complication Generation

[source,python]
----
from algebra_sofii.complications import *

# Create specific complications
expr_comp = ExpressionComplication(
    index=ExpressionIndex([0]),  # Target first operand
    operation=OperationType.ADD_ZERO,
    expr=Integer(4)
)

eq_comp = EquationComplication(
    operation=OperationType.MULTIPLY,
    expr=Integer(3)
)

# Apply to equations
equation = Equals(Unknown(), Integer(7))
complicated = expr_comp.apply(equation)
more_complicated = eq_comp.apply(complicated)
----

=== Expression Navigation

[source,python]
----
# Navigate expression trees using indices
complex_expr = Addition([
    Multiplication([Integer(2), Unknown('x')]),
    ChangedSign(Integer(3))
])

# Access subexpressions
coefficient = complex_expr[ExpressionIndex([0, 0])]  # Gets the '2'
variable = complex_expr[ExpressionIndex([0, 1])]     # Gets the 'x'
constant = complex_expr[ExpressionIndex([1, 0])]     # Gets the '3' inside ChangedSign

# Replace subexpressions
new_expr = complex_expr.replace_with(
    ExpressionIndex([0, 0]),
    Integer(5)
)  # Changes coefficient from 2 to 5
----

== API Reference

=== Core Classes

==== Expression
Base class for all mathematical expressions.

**Methods:**
- `to_sympy_expr() -> sympy.Expr`: Convert to SymPy expression
- `evaluate(true_x: int) -> Rational`: Evaluate with given x value
- `complexity() -> float`: Get complexity measure
- `negated() -> Expression`: Return negated expression
- `inverted() -> Expression`: Return inverted expression (1/expr)

==== EquationWithSolution
Container for equations with predetermined solutions.

**Methods:**
- `random_complication(max_complexity: float) -> Complication`: Generate random complication
- `apply_complication(complication: Complication)`: Apply a complication
- `get_current_equation() -> Expression`: Get current equation form
- `verify_solution() -> bool`: Verify equation still solves correctly

=== Generator Functions

==== random_expression(random_stream, complexity_target: float) -> Expression
Generate random algebraic expressions.

**Parameters:**
- `random_stream`: Random number generator
- `complexity_target`: Target complexity level

**Returns:**
Expression in form of constants, linear terms, or full linear expressions.

==== random_nonzero_expression(random_stream, complexity_target: float, true_x: int) -> Expression
Generate expressions that don't evaluate to zero.

== Examples

=== Generate Simple Practice Problems

[source,python]
----
import random
from algebra_sofii import EquationWithSolution

def generate_practice_problems(count=5, difficulty="medium"):
    """Generate practice problems for students."""
    random_stream = random.Random()
    problems = []

    complexity_map = {
        "easy": 5.0,
        "medium": 10.0,
        "hard": 15.0
    }
    max_complexity = complexity_map.get(difficulty, 10.0)

    for i in range(count):
        solution = random_stream.randint(1, 9)
        eq_gen = EquationWithSolution(solution)

        # Add 2-4 complications
        num_complications = random_stream.randint(2, 4)
        for _ in range(num_complications):
            if eq_gen.get_total_complexity() < max_complexity:
                comp = eq_gen.random_complication(max_complexity, random_stream)
                eq_gen.apply_complication(comp)

        problems.append({
            'equation': str(eq_gen.get_current_equation()),
            'solution': solution,
            'complexity': eq_gen.get_total_complexity()
        })

    return problems

# Generate problems
problems = generate_practice_problems(count=3, difficulty="medium")
for i, problem in enumerate(problems, 1):
    print(f"Problem {i}: {problem['equation']}")
    print(f"Solution: x = {problem['solution']}")
    print(f"Complexity: {problem['complexity']:.1f}")
    print()
----
